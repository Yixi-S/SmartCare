How To Make Everything Work: 
- XAMP Download Required - Once Downloaded Start Apache And MYSQL In XAMPP

- MySQL Connector Needed - Download In Terminal With Command: pip install mysql-connector-python

- There Is No Need To Install Anything Else Tkinter Is Already Built Into Python's Standard Libary

- Make Sure To Import Database Into phpmyadmin - You Can Access phpmyadmin via: localhost/phpmyadmin/ In Browser Once XAMPP Is Running And Apache And MYSQL Is Started. 

- You Can Import Database By Downloading The DB file In This Folder 

- To Import Database Open phpmyadmin, Then Click On New, And Ensure You Name The Database "smartcare" (Database Name Does Not Have Quaotations, Quotations Are Here To Outline The Databases Name) Exactly, Smartcare Or SmartCare Will Not Work It Is Case Sensitive. Once You Have Created The Database, Click On The Database, Then Find The Import Button On The Top TaskBar, Which You Can Then Click On Choose File, And Then Select The Downloaded Database File I Have Provided. 

- Do Not Change The Names Of Any Of The Tables In phpmyadmin Or Everything Will Not Work.
